# Selected Systems Work

An interactive, public portfolio of systems-software case studies. It demonstrates:

- operational investigation workflows;
- cloud-managed configuration for deployed embedded devices;
- network validation before site launch.

## Privacy

All visualizations, events, metrics, site layouts, labels, and architecture are
synthetic and simplified. Do not add:

- internal screenshots or screen recordings;
- company, customer, store, service, or product names;
- source code, URLs, identifiers, secrets, or copied architecture documents;
- production data.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
npm run lint
```

## Deployment

The GitHub Actions workflow deploys the `main` branch to GitHub Pages. Before
the first deployment, enable GitHub Pages in the repository settings and select
**GitHub Actions** as the source.
